## Описание проекта
Проект реализует обмен по шине AMBA APB: модель мастера,
которая выполняет операции записи и чтения, и slave.
Вспомогательная программа на C++ считает значения, которые записываются в регистры.

## Состав
- `student.cpp` - программа на C++ (сборка: `g++ student.cpp -o student`).

## Статус
Проект в разработке: далее будут добавлены мастер, slave и модуль верхнего уровня.
