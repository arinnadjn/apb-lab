# Лабораторная работа: APB slave на SystemVerilog

# Автор:Тищенко Арина Кареновна
# Группа: М3О-409Б-23

## Описание проекта
Проект реализует обмен по шине AMBA APB: модель мастера,
которая выполняет операции записи и чтения, и ведомое устройство (slave).

## Состав
- `apb_master.sv` - модель APB-мастера (задачи `apb_write`, `apb_read`).

## Статус
Добавлен файл мастера (задачи записи и чтения).
