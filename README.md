## Описание проекта
Проект реализует обмен по шине AMBA APB: модель мастера,
которая выполняет операции записи и чтения, и  устройство slave.
Вспомогательная программа на C++ считает значения, которые записываются в регистры.

## Состав
- `student.cpp` - программа на C++ (сборка: `g++ student.cpp -o student`).
- `apb_master.sv` - модель APB-мастера (задачи `apb_write`, `apb_read`, `apb_read_check`) и тест.
- `apb_slave.sv` - APB slave (конечный автомат SETUP / W_ENABLE / R_ENABLE).
- `top.sv` - модуль верхнего уровня: такт, сброс, соединение master и slave.
- `data.svh` - данные (номер, дата, фамилия, имя).

## Карта регистров slave
| Смещение | Назначение |
|----------|----------- |
| 0x00 | номер в списке группы |
| 0x04 | дата дд.мм.гггг       |
| 0x08 | первые 4 буквы фамилии|
| 0x0C | первые 4 буквы имени  |
| 0x10 | `register_with_some_name`: запись 0 в бит 0 -> `hAAAA_AAAA`, запись 1 -> `h5555_5555` |

Обращение по другому адресу завершается с `pslverr = 1`.

## Запуск
`./sim.sh` (Icarus) или `vsim -c -do run.do` (ModelSim).
Успешный тест заканчивается сообщением `[MASTER] TEST PASSED`.
