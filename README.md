# Лабораторная работа: APB slave на SystemVerilog

Автор: Тищенко Арина Кареновна
Группа: М3О-409Б-23

## Описание проекта
Проект реализует обмен по шине AMBA APB: модель мастера (bus functional model),
которая выполняет операции записи и чтения, и ведомое устройство (slave).
Вспомогательная программа на C++ считает значения, которые записываются в регистры.

## Состав
- `student.cpp` - программа на C++ (сборка: `g++ student.cpp -o student`).
- `apb_master.sv` - модель APB-мастера (задачи `apb_write`, `apb_read`, `apb_read_check`).
