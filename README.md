# Лабораторная работа: APB slave 

Автор:Тищенко Арина Кареновна
Группа: М3О-409Б-23

## Описание проекта
Проект реализует обмен по шине AMBA APB: модель мастера,
которая выполняет операции записи и чтения, и slave.
Вспомогательная программа на C++ считает значения, которые записываются в регистры.

## Состав
- `student.cpp` - программа на C++ (сборка: `g++ student.cpp -o student`).
- `apb_master.sv` - модель APB-мастера (задачи `apb_write`, `apb_read`, `apb_read_check`).
- `apb_slave.sv` - APB slave (конечный автомат SETUP / W_ENABLE / R_ENABLE).
- `top.sv` - модуль верхнего уровня: такт, сброс, соединение master и slave.
- `sim.sh` - Verilog; `run.do` - з ModelSim

## Логика slave 
Регистр `register_with_some_name` по смещению 0: при записи 0 в младший бит
сохраняется `hAAAA_AAAA`, при записи 1 - `h5555_5555`. Slave печатает сообщения
о каждой операции чтения/записи.
